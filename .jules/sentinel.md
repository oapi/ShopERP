## 2026-09-12 - Path Traversal bypass via URL decoding and Partial directory matching
**Vulnerability:** Path traversal to access out-of-boundary sensitive files (e.g. `secret.txt` from a sibling `public-secret` directory and `../../package.json` when using encoded payload).
**Learning:** `new URL()` automatically resolves `/../` sequences in the URL. If `decodeURIComponent` is applied *after* URL parsing, URL-encoded path separators (e.g. `%2E%2E%2F`) are left unresolved by `URL` but later parsed into `/../`. Also `startsWith(PUBLIC_DIR)` allows access to sibling directories when `PUBLIC_DIR` doesn't end with a trailing slash (e.g., `/app/public` matches `/app/public-secret`).
**Prevention:** Always use `path.relative(ROOT_DIR, targetPath)` and check if the result is out of bounds (`relativePath === '..' || relativePath.startsWith('..' + path.sep) || path.isAbsolute(relativePath)`). And return `404 Not Found` instead of `403 Forbidden` to prevent directory structure leakage.
