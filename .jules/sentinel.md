## 2024-11-05 - Fix Path Traversal in Static File Serving
**Vulnerability:** The static file serving implementation in `server.js` was vulnerable to path traversal (CWE-22) due to how `new URL()` and `decodeURIComponent` handle URL paths and encoding, specifically `%2f` which bypasses `URL` parsing logic and allowed an attacker to request files outside `PUBLIC_DIR`.
**Learning:** `new URL()` does not decode `%2f` (slash) as a directory separator, meaning paths like `/%2e%2e%2f` bypass URL normalization. When `decodeURIComponent()` is applied after `new URL()`, it can reintroduce path traversal sequences (`../`) that evade initial URL parsing. Using `startsWith(PUBLIC_DIR)` as boundary enforcement is also insecure because it's vulnerable to prefix matching.
**Prevention:** Always validate that resolved file paths fall strictly within the intended base directory by calculating the relative path (`path.relative(PUBLIC_DIR, filePath)`) and ensuring it does not start with `..` or is an absolute path.
