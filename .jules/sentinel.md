## 2026-08-29 - Path Traversal Bypass via `decodeURIComponent` and `startsWith`
**Vulnerability:** The native Node.js static file router was vulnerable to Path Traversal, allowing arbitrary file read (e.g., `/db.js`) despite a basic `startsWith(PUBLIC_DIR)` boundary check.
**Learning:** In Node.js native routing, `new URL()` does not automatically normalize URL-encoded path separators like `%2E%2E%2F`. When `decodeURIComponent()` is subsequently called on `url.pathname`, these sequences decode into active directory traversal elements (`../`). Because a simple string prefix match like `filePath.startsWith(PUBLIC_DIR)` does not resolve directory boundaries properly, an attacker can bypass the check by requesting sibling files (e.g. `/public_secret`) or by traversing up using decoded sequences (e.g., `/%2E%2E/db.js` decoding to `/app/public/../db.js` which normalizes to `/app/db.js` but failed the original check).
**Prevention:** Never rely on simple string matching (`startsWith`) to enforce file boundaries when serving static files. Always compute the relative path from the target directory using `path.relative(TARGET_DIR, requestedFile)` and strictly verify that the result does not start with `..` and is not an absolute path.
