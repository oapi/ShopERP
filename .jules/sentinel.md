## 2025-01-28 - URL Decoder Path Traversal Bypass
**Vulnerability:** Path traversal bypass in static file serving despite `.startsWith()` boundary checks.
**Learning:** In Node.js native routing, `new URL()` does not normalize URL-encoded path separators (e.g., `%2E%2E%2F`). If `decodeURIComponent()` is called on `url.pathname` afterwards, the encoded sequences become active traversal elements (`../`). When concatenated with the public directory path, `path.normalize` collapses the traversal, but this can cause the resulting path to successfully bypass simple prefix matching like `startsWith(PUBLIC_DIR)` if the target path happens to start with a prefix matching the public directory string, or if there's no trailing slash in the `startsWith()` comparison leading to partial directory name match exploits.
**Prevention:** Always use `path.relative(ROOT_DIR, targetPath)` to determine if the path resolves to an internal/child directory. Verify the relative path does not equal `..`, start with `..` followed by a separator, and is not an absolute path.
