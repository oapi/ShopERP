## 2026-08-18 - Path Traversal bypass via URL-encoded sequences with decodeURIComponent
**Vulnerability:** A path traversal bypass was discovered in the static file routing where `filePath.startsWith(PUBLIC_DIR)` was used to prevent directory traversal out of the `public/` directory. By sending URL-encoded path segments like `%2E%2E%2F` or utilizing sibling directories with encoded parts (e.g. `/%2e%2e/public_not/`), an attacker could access arbitrary files outside the intended root.
**Learning:** In Node.js native routing, `new URL()` does not normalize URL-encoded path separators (e.g., `%2E%2E%2F`). If `decodeURIComponent()` is called on `url.pathname` afterwards, the encoded sequences become active traversal elements (`../`). Using `.startsWith()` prefix checks is flawed because it allows accessing sibling directories that start with the same prefix (e.g., `public_not`).
**Prevention:** Always use `path.relative(baseDir, resolvedPath)` and ensure the result does not equal '..', start with '..' + path.sep, or resolve to an absolute path to validate boundaries securely.
