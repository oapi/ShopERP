## 2024-05-24 - Accessibility gaps in dynamically generated Vanilla JS templates
**Learning:** Dynamically generated string templates in Vanilla JS (e.g. `modal.innerHTML = '...<button>&times;</button>'`) bypass standard static analysis tools and linting checks for accessibility. This leads to hidden accessibility gaps, particularly with icon-only buttons (like modal close buttons, row removal, or pagination arrows) which lack `aria-label` or semantic text, making them invisible or confusing to screen reader users. Furthermore, pagination controls built this way often lack `aria-current="page"` for active states.
**Action:** When working on Vanilla JS SPAs or modifying dynamic templates, manually inspect raw HTML strings for interactive elements. Explicitly ensure `aria-label` and `title` attributes are included on all icon-only elements (like `&times;` buttons) and semantic ARIA states are correctly handled during dynamic template injection.
