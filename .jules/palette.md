## 2024-09-16 - Vanilla JS Dynamic DOM Accessibility
**Learning:** When using vanilla JS to dynamically construct HTML strings for UI components (like modals, tables, and pagination), native interactive elements (especially icon-only buttons like `&times;` or `◀`) completely lack semantic context for screen readers. Since this app heavily relies on string concatenation for rendering views (e.g., in `public/app.js`), developers often overlook adding `aria-label` and `title` attributes to these generated elements.
**Action:** When creating or modifying dynamically generated UI components in vanilla JS string templates, explicitly include `aria-label` (for screen readers) and `title` (for visual tooltips) on all icon-only interactive elements to ensure accessibility standards are met.
