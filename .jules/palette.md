## 2024-05-14 - Vanilla JS String Interpolation Bypasses Accessibility Linting
**Learning:** In projects using Vanilla JS with dynamic string template interpolation (`innerHTML` concatenation) rather than a declarative framework like React or Vue, standard static analysis linting for accessibility (like ESLint plugin `jsx-a11y`) completely misses accessibility violations. We discovered that multiple icon-only buttons (`&times;` and pagination arrows) lacked `aria-label` and `title` attributes because they were deeply embedded in dynamically generated HTML strings.
**Action:** When working on Vanilla JS codebases that generate DOM elements manually via strings, do not rely solely on automated linter feedback for accessibility. Proactively audit string concatenations (e.g., `grep "<button" app.js`) and inject `aria-label` and `title` attributes directly into the HTML string definitions.
