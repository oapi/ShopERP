## 2024-11-20 - Consolidate Multiple Table Aggregations to Prevent N+1 Penalty
**Learning:** In the `server.js` balance calculation helpers (`customerBalance`, `accountBalance`, etc), fetching single scalar values iteratively creates an enormous N+1 database round-trip overhead. We found that calculating 5 separate `SUM()` operations independently for `accountBalance` was taking ~10ms for 1000 users. By consolidating all conditional aggregations using `CASE WHEN` and sub-queries, and hoisting `db.prepare()` outside the function scope, we reduced runtime to ~1ms. This pattern is exceptionally critical for SQLite interactions within Node.js event loops.
**Action:** When calculating composite sums (e.g. subtracting payments from due balances), use a single pre-compiled `db.prepare` SQL query relying on conditional `CASE` logic or embedded scalar sub-queries, instead of making multiple queries sequentially in JS.
