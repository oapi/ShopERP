## 2024-03-24 - Pre-compiling SQLite Queries for Loop Iterations
**Learning:** In Node.js native `node:sqlite`, using `db.prepare()` inside loops or `map` functions like `items.map(it => db.prepare('SELECT ...').get(it.id))` causes severe compilation overhead. This is a common performance bottleneck in bulk operations (like importing CSVs) or saving sales/purchases with multiple items. Moving `db.prepare()` outside the iteration block and caching the compiled statement significantly improves execution time (from ~120ms to ~13ms for 1000 items in a quick benchmark).
**Action:** When working with `node:sqlite` in a loop, always check if the query can be pre-compiled outside the loop. Refactor instances where `db.prepare` is called inside `.map`, `.forEach`, or `for` loops within route handlers.
