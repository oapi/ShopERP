## 2024-04-20 - Module-level Query Caching & Conditional Aggregation in sqlite
**Learning:** In Node's built-in sqlite (`node:sqlite`), creating new prepared statements (`db.prepare(...)`) inside frequently called functions (such as when iterating over rows and mapping data) adds significant compilation overhead. Additionally, executing multiple separate queries against the same table when one conditional query could suffice creates N+1 query like overhead.
**Action:** When performing calculations like sum aggregations across multiple conditions on the same table, combine them into a single query using conditional aggregation (`SUM(CASE WHEN ... ELSE 0 END)`). Always pre-compile these and other frequently used queries with `db.prepare()` at the module scope so they are compiled exactly once, drastically reducing execution time (measured up to 5x faster in tight loops).
