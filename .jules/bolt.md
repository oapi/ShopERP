## 2024-05-24 - Account Balance Query Consolidation
**Learning:** In the `server.js` file, the `accountBalance` function was previously executing 5 sequential database queries (1 for `opening_balance` and 4 distinct `SUM` combinations). Because it dynamically invoked `db.prepare()` on every call, `node:sqlite` had to recompile the query repeatedly, exacerbating the N+1 problem inside loops like the `/api/accounts` endpoint list generation.
**Action:** Replaced the 4 distinct `SUM(...)` queries with a single query using conditional aggregation (`SUM(CASE WHEN condition THEN amount ELSE 0 END)`). Additionally, hoisted `db.prepare()` outside the function to the module level. This reduced execution time by ~93% (from ~527ms to ~37ms for 100 loop iterations) by compiling the statement exactly once at application startup.
